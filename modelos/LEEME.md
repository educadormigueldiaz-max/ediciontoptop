# Modelos

## caras-ultraface-640.onnx

Detector de caras usado por `npm run preparar` y `npm run caras` para que los textos y
gráficos nunca tapen la cara. Corre en tu computadora, sin internet.

- Origen: `version-RFB-640.onnx` de
